# Plan: Synkronisering mellem enheder via GitHub Gist

Planlagt og implementeret af Claude Opus efter aftale med Alexander (2026-11-15).

## Mål

Projekterne skal kunne bruges på flere enheder. Appen er en statisk side på GitHub Pages og har ingen server, så data synkroniseres til en privat (hemmelig) Gist på brugerens egen GitHub-konto. Den lokale lagring i browseren er uændret og er stadig den primære kopi. Synkronisering er frivillig og slås til med et token.

## Opsætning for brugeren

1. Opret et klassisk token med kun `gist`-adgang (link i appen).
2. Indsæt tokenet under Dokumentation → Synkronisering og tryk Forbind.
3. Appen finder en eksisterende Gist med filen `tavleoversigt.json` på kontoen eller opretter en ny hemmelig Gist.
4. Gentag på hver enhed med samme token (eller et nyt token til samme konto).

## Gist-format

| Fil | Indhold |
|---|---|
| `tavleoversigt.json` | Markør: `{ format:'tavleoversigt-sync', app, schema, opdateret }` |
| `tavleoversigt-<id>.json` | Ét projekt som JSON, samme format som `tavleoversigt.p.<id>` |

## Lagring (ny nøgle)

`tavleoversigt.sync` = `{ token, gistId, login, base:{ <id>: <hash> }, sidst }`. `base` er hashen af hvert projekt, som det så ud ved seneste vellykkede synkronisering. Eksisterende nøgler ændres ikke. `SCHEMA` hæves ikke, fordi projektets datamodel er uændret.

## Fletning (tre-vejs pr. projekt)

Hash = `cyrb53(JSON.stringify(norm(data)))`. For hvert projekt-id sammenlignes lokal (L), fjern (R) og base (B):

| Situation | Handling |
|---|---|
| L = R | Intet, base = L |
| L ændret, R = B | Skub L |
| R ændret, L = B | Hent R (aktivt projekt genindlæses, fortryd-historik nulstilles) |
| Begge ændret | Behold L, hent R som kopi med navnet "(fra anden enhed …)". Intet går tabt |
| Kun L, ingen B | Nyt lokalt: skub. Uændrede eksempelprojekter skubbes ikke |
| Kun R, ingen B | Nyt fjernt: hent |
| Kun L, B findes | Slettet på anden enhed: slet lokalt hvis L = B, ellers skub L igen |
| Kun R, B findes | Slettet lokalt: slet fjernt hvis R = B, ellers hent R igen |

Alle ændringer til Gist'en sendes i én `PATCH`. Filer over 1 MB, som API'et afkorter, hentes fra `raw_url`.

## Hvornår der synkroniseres

- Ved start, hvis forbundet.
- 4 sekunder efter seneste `save()` (debounce).
- Når fanen bliver synlig igen.
- Med knappen "Synkronisér nu".

Kun én kørsel ad gangen. En anmodning under en kørsel giver én ny kørsel bagefter.

## Berørte funktioner

`init`, `save`, `sletProjekt` (ingen ændring nødvendig; sletning opdages via base), nye: `synk*`-funktioner, `hashTxt`, `erEksempel`. UI: nyt panel i Dokumentation og status i hovedet.

## Test

- Røgtesten skal stadig slutte med `OK` (synk er slået fra uden token).
- Ny del i røgtesten med en falsk GitHub-API i Playwright: to browserkontekster deler én Gist, opretter, retter og sletter projekter og kontrollerer fletning og konflikt-kopi.
