# Planer

Skriftlige planer før en ændring implementeres. Claude Opus må planlægge alle opgaver, og Claude Fable må gennemgå og ændre enhver plan. Navngiv filen `ÅÅÅÅ-MM-DD-emne.md`, og beskriv:

- mål
- hvem der skal udføre den (Fable, Opus eller Sonnet) og hvorfor
- berørte funktioner
- ændringer i datamodellen
- hvordan det testes

Ændrer Fable en plan, noteres det nederst med dato og begrundelse.
